# ECMenu Spec

ECMenu 是一个固定提供高频文件操作的 macOS Finder 右键扩展。核心操作直接出现在一级菜单，正常执行保持静默，产品以原生、低配置和可预测为原则。

## 阅读路径

- [当前需求](Requirements/Main.md)：产品行为与验收边界。
- [技术知识](Technical/Main.md)：平台契约、项目实测、跨模块约束与设计动机。
- [未来提案](Proposals/Main.md)：已经形成稳定设计、但尚未进入当前产品范围的能力。

具体控制流、类型和文件职责由源码与测试表达；当前需求和技术知识只保存无法从单个源码位置可靠恢复的事实，尚未进入产品范围的稳定设计只进入未来提案。各目录通过链接关联，不重复维护同一结论。
