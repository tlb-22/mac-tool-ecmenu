# 文件模板

模板能力管理应用保存的普通文件副本、模板名称和有序清单，向新建文件命令提供一次读取的元数据与字节快照。管理界面、编辑会话、应用操作和存储由主应用拥有；Finder Extension 只接收模板 ID 与菜单显示名。

产品行为与验收边界见[模板管理需求](../../../Requirements/Features/NewFile.md#模板管理)和[文件模板页面](../../../Requirements/StatusPage.md#文件模板)。创建输出文件属于独立的[新建文件能力](../NewFile.md)。

## 关键边界

- `FileTemplateLibrary` actor 唯一持有已提交索引，`FileTemplateStorage` 执行同步文件 I/O；视图、编辑草稿和菜单副本不修改索引。
- `FileTemplateOperations` 是生产读取和修改入口，协调初始化、管理页可用性确认与提交发布；普通缓存查询不发送变更提示。
- 索引提交与副本清理分别完成。`FileTemplateCommit` 携带权威清单，明确表示已提交或已提交且存在清理问题；库变更方法抛错表示提交前失败。
- 页面先应用已提交清单，再呈现删除清理错误；更换后的清理问题写日志。名称提交失败保持现有列表、原生控件和草稿。
