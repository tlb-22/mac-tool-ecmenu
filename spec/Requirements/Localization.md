# 语言

ECMenu 支持英文（`en`）和简体中文（`zh-Hans`）。所有面向用户的应用菜单、状态页、Finder 菜单、业务窗口、辅助功能文字和错误反馈均使用当前语言；产品名称与外部应用名称保持不变。

界面跟随 macOS 的语言选择，不提供应用内语言开关。英文是源语言和不支持语言的回退；切换语言后，相关应用与 Finder Extension 进程重新启动时使用新语言。

命令身份、保存的菜单配置和跨进程协议不依赖显示语言。两种语言中的同一命令始终共享相同身份、顺序、图标和行为。

本地化资源与跨进程边界见[本地化](../Technical/Runtime/Localization.md)。
