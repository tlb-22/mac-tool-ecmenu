# Finder 菜单

## 结构与顺序

产品功能直接进入 Finder 一级右键菜单。“新建文件”展开一层模板子菜单，每个模板对应一个叶子；其余功能直接执行对应命令。

菜单默认按以下顺序排列，用户可以在右键菜单设置页调整 ECMenu 一级入口的顺序，命令之间不插入分隔线：

| 顺序 | 英文 | 简体中文 |
|---|---|---|
| 1 | `New File` | `新建文件` |
| 2 | `Copy Path` | `拷贝路径` |
| 3 | `Hide Items` | `隐藏项目` |
| 4 | `Show Items` | `显示项目` |
| 5 | `Compress Images` | `压缩图片` |
| 6 | `Open in Visual Studio Code` | `进入 Visual Studio Code` |
| 7 | `Open in iTerm2` | `进入 iTerm2` |

固定功能入口使用符合功能语义的图标；同一功能在 Finder 菜单、状态页和进度窗口中使用一致的名称与图标。模板子菜单使用用户配置的显示名，其名称和顺序规则见[新建文件](Features/NewFile.md)。

Finder 按保存的顺序显示当前适用的 ECMenu 入口，隐藏项保留其配置位置，重新显示时回到该相对位置。“新建文件”连同完整子菜单作为一个一级入口移动，子菜单内部顺序由文件模板页管理。排序范围不包含 Finder 自身及其他扩展的菜单项。

## 显示规则

核心原则是，当一个命令不可用、或能简单确认操作无结果时，则不显示该命令。具体来说，菜单叶子符合以下任一条件时不显示：

- 用户关闭了对应命令的显示开关。
- 当前 Finder 上下文没有对应语义。
- 命令依赖的外部应用不可用。
- 根据菜单构建时已经获得的状态，可以确定没有任何对象需要改变。

其余语义适用的命令均显示且可用。菜单构建不预检文件或父目录写权限、卷是否只读以及“完全磁盘访问”状态；这些条件只在执行命令时检查。

关闭总开关后不显示任何 ECMenu 命令，但保留各命令原有的显示配置。总开关与各命令开关的界面行为见[状态页](StatusPage.md)。

没有模板或主应用报告模板库不可用时，不显示“新建文件”父菜单；关闭该功能的显示开关时隐藏整个模板子菜单。模板库不可用不影响其他命令的显示配置。

- [拷贝路径](Features/CopyPath.md#菜单与操作对象)
- [隐藏项目 / 显示项目](Features/Visibility.md#操作对象)
- [压缩图片](Features/ImageCompression.md#菜单与输入)
