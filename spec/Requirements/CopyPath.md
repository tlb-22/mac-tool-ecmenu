# 拷贝路径

## 正常行为

菜单名称为 `拷贝路径`。该名称与 macOS Finder 的“拷贝”和“拷贝为路径名称”术语保持一致。

显示开关启用时，菜单在以下上下文可用：

| Finder 上下文 | 拷贝对象 |
|---|---|
| 目录空白处 | 当前可见目录本身；忽略窗口中残留的选中项 |
| 单个或多个选中项目 | 全部选中项目 |
| 侧边栏项目 | 该项目 |

剪贴板内容使用绝对 POSIX 路径：

```text
/Users/me/Projects/demo/index.ts
```

- 不包含 `file://`。
- 不执行 shell escaping，路径中的空格保持原样。
- 文件夹路径不添加尾随 `/`。
- 多选时按 Finder 提供的选择顺序每个项目写一行，不自行排序。
- 最后一行末尾不额外添加换行符。
- 符号链接拷贝链接目录项自身的路径，不解析链接目标；断开的符号链接仍可拷贝其路径。
- 成功写入系统通用剪贴板后保持静默。

## 异常行为

- Finder 上下文无法解析、主应用检查时任一目标已经不存在或剪贴板写入失败时，记录本地日志并播放一次系统默认错误提示音，不显示弹窗。
- 主应用检查时多选中的任一目标已经失效，则不写入不完整的路径集合。
- 剪贴板已经清空但字符串写入失败时，不恢复先前的剪贴板内容。
