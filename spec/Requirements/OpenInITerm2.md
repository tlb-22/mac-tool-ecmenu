# 进入 iTerm2

## 正常行为

菜单名称为 `进入 iTerm2`。命令只接受一个文件夹，并让 iTerm2 以该文件夹作为工作目录打开 window。

| 选择 | 行为 |
|---|---|
| 目录空白处 | 进入当前 Finder 目录 |
| Finder 侧边栏中的文件夹 | 进入该文件夹 |
| 单个文件夹 | 进入该文件夹 |
| 单个文件 | 不显示菜单 |
| 多选 | 不显示菜单 |

- 目录空白处按当前目录语义处理，即使 Finder 仍保留选择，也不把选择视为本次目标。
- package 按文件系统目录处理，不读取 Finder 的 package 标记，因此 `.app`、`.framework` 等可以作为工作目录。
- 符号链接跟随最终目标判断是否为目录，但交给 iTerm2 的仍是用户选中的原始路径；指向文件或已经断开的符号链接不显示菜单。

- 使用 Launch Services 检测 `iTerm.app`，不回退到其他终端应用。
- 未检测到应用时，Finder 不显示该命令；状态页的安装状态与显示开关遵循[右键菜单设置](Main.md#右键菜单)的统一行为。
- 成功时保持静默。

## 异常行为

- 菜单显示后应用被移除、目录失效、应用无法启动或工作目录无法打开时显示错误弹窗，正文统一为“无法进入 iTerm2。”；详细原因只写入日志。
