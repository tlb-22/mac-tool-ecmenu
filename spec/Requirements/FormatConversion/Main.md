# 图片 / PDF 格式转换【暂不实现】

本目录是未来需求草案，不属于当前产品的功能集合、菜单设计或验收范围。以下内容仅定义未来实现时的预期行为。

## 正常行为

`转换格式` 是一级菜单，其二级目标格式依次为 PNG、JPG、HEIC、WebP、TIFF、GIF、BMP 和 PDF，并根据选择集合省略不可用目标。

支持同一组格式作为输入和输出。`.jpg` 与 `.jpeg` 均属于 JPG 输入，JPG 输出扩展名统一为 `.jpg`。

## 输入模型

- PNG、JPG、HEIC、WebP、TIFF、BMP 是静态图片，每个文件固定产生一个图像帧。
- GIF 是容器输入，解码全部帧。
- PDF 是容器输入，渲染全部页面。
- GIF 和 PDF 作为输出时分别是单帧 GIF 和单页 PDF。

所有转换遵循 `输入 → 解码为一个或多个图像帧 → 每帧独立编码`。详细行为见：

- [选择集合与转换矩阵](Matrix.md)
- [质量、输出与错误](Output.md)

## 菜单可用性

- 单个受支持文件显示 `转换格式`。
- 多个静态图片可以批量转换。
- 同类型的多个 GIF 或同类型的多个 PDF 可以批量转换。
- 静态图片与容器输入混选、GIF 与 PDF 混选、选择集合中包含文件夹或不支持格式时，不显示该菜单。
- 与所有输入均相同、不会改变任何对象的目标格式不显示。
