# 应用生命周期

配置界面关闭后，应用仍可在后台执行 Finder 命令；配置会话是否打开决定应用的可见形态。

## 配置会话

- 用户普通打开或重新打开应用时打开配置会话：只显示一个状态页，应用以普通前台形态出现在程序坞中。
- 最小化状态页不会关闭配置会话，应用仍留在程序坞中。
- 用户点击状态页关闭按钮、在状态页按 `Command-W`，或选择 `Command-Q` 时关闭配置会话：状态页关闭，应用从程序坞中消失，但 Finder 命令和已经开始的任务继续运行。
- 配置会话关闭后再次打开应用时，只恢复同一个状态页，不启动第二个应用实例。

压缩参数、错误反馈和任务进度等业务窗口不属于状态页；它们的出现和关闭不改变应用的呈现形态。需要用户输入的业务窗口可以成为当前窗口，进度窗口继续遵守自身的非主动抢焦点规则。

## 登录启动与后台运行

- “登录时打开”开启且已经获得系统批准时，后续登录在后台启动应用：不打开状态页、不显示程序坞图标，也不激活应用。用户之后普通打开应用时再打开配置会话。
- macOS 不得因为应用在注销时仍然运行而通过会话恢复再次打开配置界面；后续登录是否启动只由“登录时打开”控制。
- Finder 命令在配置会话打开和后台运行两种形态下都可执行。后台命令不得自动打开状态页、让应用出现在程序坞中或为无界面操作抢占焦点。

关闭配置会话不会退出应用。应用进程在当前会话中被强制退出或崩溃后，Finder Extension 可以继续显示已有菜单，但点击命令会失败并播放一次系统默认错误提示音；用户重新打开应用后恢复执行。

系统重启或再次登录后，已经开启并获批准的“登录时打开”自动恢复后台运行；否则需要用户普通打开应用。

进程职责和 IPC 投递语义见[运行时总述](../Technical/Runtime/Main.md)与[IPC](../Technical/Runtime/IPC.md)。
