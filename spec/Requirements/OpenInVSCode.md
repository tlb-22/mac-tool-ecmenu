# 进入 Visual Studio Code

## 正常行为

菜单名称为 `进入 Visual Studio Code`。

| 选择 | 行为 |
|---|---|
| 目录空白处 | 将当前目录作为项目打开 |
| Finder 侧边栏中的文件夹 | 将该文件夹作为项目打开 |
| 单个文件夹 | 将该文件夹作为项目打开 |
| 单个文件 | 直接打开该文件，不替换为父目录项目 |
| 多选 | 不显示菜单 |

- 目录空白处按当前目录语义处理，即使 Finder 仍保留选择，也不把选择视为本次目标。
- package 按文件系统目录处理，不读取 Finder 的 package 标记。
- 符号链接跟随最终目标判断是否有效，但交给 VS Code 的仍是用户选中的原始路径；断开的符号链接不显示菜单。
- 项目不指定新窗口或复用窗口，由 VS Code 自身的窗口设置决定。
- 使用 Launch Services 检测 `Visual Studio Code.app`，不依赖 `code` CLI 或用户的 `PATH`。
- 未检测到应用时，Finder 不显示该命令；状态页的安装状态与显示开关遵循[右键菜单设置](Main.md#右键菜单)的统一行为。
- 成功时保持静默。

## 异常行为

- 菜单显示后应用被移除、目标失效、应用无法启动或目标无法打开时显示错误弹窗，正文统一为“无法进入 Visual Studio Code。”；详细原因只写入日志。
