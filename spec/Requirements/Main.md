# 产品需求

ECMenu 是一个轻量的 macOS Finder 右键扩展，面向个人日常开发和文件管理。当前产品最低支持 macOS 26.0。

## 产品边界

产品提供一组固定的 Finder 命令及其必要设置，不扩展为通用右键工具箱。当前范围不包含账号、云同步、AI、插件、自定义脚本或模板、归档文件压缩与解压、OCR、PDF 编辑、剪贴板历史或文件移动增强。

所有文件处理均在本机完成；产品不发送网络请求，不上传文件名、路径或内容，也不集成遥测、分析或崩溃采集服务。
