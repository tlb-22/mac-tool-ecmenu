# 需求总述

## 产品定位

ECMenu 是一个轻量的 macOS Finder 右键扩展，为个人日常开发和文件管理固定提供六类操作：

1. [新建 TXT](NewTextFile.md)
2. [进入 Visual Studio Code](OpenInVSCode.md)
3. [进入 iTerm2](OpenInITerm2.md)
4. [压缩图片](ImageCompression.md)
5. [隐藏项目 / 显示项目](Visibility.md)
6. [拷贝路径](CopyPath.md)

当前产品最低支持 macOS 26.0。

功能集合、名称与菜单顺序由产品固定；每个功能可以独立选择是否在 Finder 中显示。新建类型固定为 TXT，编辑器固定为 VS Code，终端固定为 iTerm2。

产品不扩展为通用右键工具箱：不包含账号、云同步、遥测、AI、插件、自定义脚本或模板、压缩解压、OCR、PDF 编辑、剪贴板历史或文件移动增强，也不以 Mac App Store 架构为目标。

## 菜单设计

核心操作直接进入 Finder 一级右键菜单，不增加统一的产品父菜单或功能二级菜单。

一级菜单中的本地处理命令按 `新建 TXT`、`拷贝路径`、`隐藏项目`、`显示项目`、`压缩图片` 排列，随后是进入外部应用的命令；彼此之间不插入分隔线。

每个命令显示固定且与功能语义相符的图标；同一命令在 Finder 菜单、状态页和进度窗口中使用一致的名称与图标。

功能的显示开关关闭后，该功能不出现在任何 Finder 上下文中；重新开启后继续遵守原有上下文规则，执行行为不变。

菜单叶子的显示遵循以下规则：

- 功能被用户隐藏、命令在当前上下文中没有对应语义、缺少必要外部依赖，或已经能够确定没有会改变的对象时，不显示。
- 其余语义适用的命令显示且可用。菜单构建不预检文件或父目录写权限、卷是否只读以及“完全磁盘访问”状态；这些条件在实际执行时检查并进入对应错误反馈。

菜单按触发位置和选择集合显示：

| Finder 上下文 | 显示的操作 |
|---|---|
| 目录空白处 | 新建 TXT、拷贝路径、进入 Visual Studio Code、进入 iTerm2 |
| 单个普通文件 | 新建 TXT、拷贝路径、按隐藏状态显示隐藏项目或显示项目、VS Code；可处理图片另有压缩图片 |
| 单个文件夹 | 新建 TXT、拷贝路径、按隐藏状态显示隐藏项目或显示项目、VS Code、iTerm2 |
| 多个文件 | 拷贝路径、按选中项状态显示隐藏项目和/或显示项目；全部为可处理图片时显示压缩图片 |
| 多个文件夹 | 拷贝路径、按选中项状态显示隐藏项目和/或显示项目 |
| 文件和文件夹混选 | 拷贝路径、按选中项状态显示隐藏项目和/或显示项目 |

外部依赖未安装时不显示对应 Finder 命令。隐藏与显示命令的状态判断矩阵见[隐藏项目 / 显示项目](Visibility.md)。

## 长时间命令进度

只有主动提供确定进度的命令才进入主应用共享任务窗口。实际工作持续约一秒后才显示，快速完成时不闪现界面。

进度窗口遵循以下布局：

- 窗口标题为 `ECMenu`。标题栏的关闭和最小化按钮可用，缩放按钮禁用。
- 每个任务占一行，左侧显示命令图标，右侧依次显示命令名称、确定进度条与取消按钮、`已处理数 / 总数`；不显示剩余时间估算。
- 窗口非焦点时进度使用系统非强调色；用户主动聚焦后使用系统强调色。

多个长任务共用同一个非模态窗口，按任务行独立显示和更新，不抢占 Finder 焦点，也不阻塞其他右键命令。当前提供进度的压缩图片命令同时实现项目边界取消，因此每个任务行都显示取消按钮。

任务结束后移除对应行，没有任务时自动关闭窗口。用户关闭窗口只隐藏关闭瞬间已经显示的任务，不取消它们；这些任务不会随窗口再次出现，之后开始并达到显示阈值的新任务仍可重新显示窗口。

## 文件系统范围

- 本机启动磁盘上的 Finder 目录属于核心范围，包括用户目录和 `/Applications`。
- Finder 中可见的非隐藏挂载卷属于核心范围，包括挂载在 `/Volumes` 下的外置磁盘及其任意深度子目录。
- 应用运行期间新挂载、卸载或重命名卷后，Finder 菜单范围应自动更新，不要求用户重启应用或 Finder。
- 文件操作不得在点击动作后弹出逐文件夹授权面板。
- Finder 扩展启用和“完全磁盘访问”属于应用状态页可引导的一次性系统设置。
- 实际操作仍遵守文件系统写权限、只读卷和 macOS 系统完整性保护。

## 应用呈现与运行生命周期

主应用使用同一个常驻进程承载配置界面和右键命令执行，并按配置会话是否打开切换呈现形态：

- 用户普通打开或重新打开应用时打开配置会话：只显示一个状态页，应用以正式应用图标和普通前台形态出现在程序坞中。最小化状态页不会关闭配置会话，应用仍留在程序坞中。
- “登录时打开”开启且已经获得系统批准时，后续登录会只启动后台命令宿主：不打开状态页、不显示程序坞图标，也不激活应用。用户之后普通打开应用时，当前进程再打开配置会话。
- macOS 不得因为应用在注销时仍然运行而通过会话恢复再次打开配置界面；是否在后续登录中启动主应用只由“登录时打开”控制。
- 用户点击状态页关闭按钮、在状态页按 `Command-W`，或选择 `Command-Q` 时关闭配置会话：状态页关闭，应用从程序坞中消失，但命令宿主和已经开始的任务继续运行。`Command-Q` 在本产品中表示关闭配置会话，不终止常驻命令宿主。
- 配置会话关闭后再次打开应用时，复用当前进程和同一个状态页并重新打开配置会话，不启动第二个命令宿主。
- Finder 命令在两种呈现形态下都可执行。后台命令不得自动打开状态页、让应用出现在程序坞中或为无界面操作抢占焦点。
- 压缩参数、错误反馈和任务进度等业务窗口不属于状态页；它们的出现和关闭不改变应用的呈现形态。需要用户输入的业务窗口可以成为当前窗口，进度窗口继续遵守自身的非主动抢焦点规则。

常驻保证从主应用启动后开始，持续到进程被系统或用户在进程层面终止。主进程遭遇强制退出、崩溃或注销后，Finder Extension 可以继续显示已有菜单，但命令会因宿主缺席而失败并播放系统默认错误提示音；用户重新打开应用后恢复命令宿主。系统重启或再次登录后，已开启并获批准的“登录时打开”会自动恢复后台命令宿主，否则仍需用户普通打开应用。

Finder Extension 对每次菜单点击只向当前命令宿主发送一次命令，不自动重试，也不等待命令接管 ACK 或业务执行结果。双方完成运行态身份验证后，主应用返回一个不携带命令接管或业务状态的认证就绪 ACK，Extension 随后才发送命令正文。连接建立、对端身份验证、认证就绪 ACK、编码或完整写入失败时播放一次系统默认错误提示音；完整写入成功只表示本次点对点发送完成，后续命令恢复、执行和结果反馈由主应用负责。菜单配置仍由 Extension 向主应用请求当前快照并等待响应，不与单向命令投递共用可靠性交付语义。

## 正常行为原则

- 正常操作直接执行，不要求二次确认。
- Finder Extension 只采集菜单事件；所有功能动作由主应用统一执行。
- 成功完全静默。
- 批量操作允许部分成功，已成功项目不回滚。
- 不覆盖已有文件，不隐式删除或修改源文件。
- 不发送网络请求，不上传文件名、路径或内容，不集成分析与崩溃采集服务。
- Release 日志避免持久记录完整用户路径；Debug 日志可用于本地诊断。

## 异常行为原则

- 权限不足或只读文件系统错误统一显示为“没有写入权限”，不在用户文案中区分底层原因。
- 所有命令错误弹窗的标题固定为“操作未完成”；正文只写简要原因，不显示系统原始错误、完整路径、解决方案或设置入口。单个失败对象显示名称，多个同类失败对象只显示数量，多种问题各占一行。
- 除外部应用命令按各自需求显示固定失败说明外，目标失效、上下文无法解析和其他一般不会发生的错误，只播放一次系统默认错误提示音，详细原因写入本地日志。
- 批量操作同时包含两类错误时只显示汇总弹窗，不再额外播放提示音。

## 应用界面

应用提供简洁的双栏状态页。较窄的左栏从上到下显示应用图标、版本号和页面导航；导航只有以下两项，均使用图标和标题：

- `通用`
- `右键菜单`

导航与设置行图标保持统一的视觉度量和对齐方式。

首次打开默认进入“通用”；后续打开恢复用户上次选择的页面。左栏使用系统侧边栏选择行为，鼠标按下选项时立即完成选择并同步切换右栏内容。列表背景与窗口其余区域一致。右栏显示当前页面的内容，不重复产品说明；当前不可操作的控件使用系统禁用状态和灰色外观。

### 通用

通用页不为两组内容另加标题：

- 开关组提供“启用 ECMenu”和“登录时打开”。每行左侧使用图标和标题，右侧使用开关。
  - “启用 ECMenu”默认开启；关闭后 Finder 不再显示任何本产品菜单，但保留每项功能原有的显示配置，已经开始的任务继续执行。Finder Extension 未启用时，仅此行整体使用系统禁用的灰色外观且不可操作，开关仍显示并保留用户保存的值；“登录时打开”、系统设置入口和右键菜单配置不受影响。
  - “登录时打开”默认关闭。开启表示申请让主应用在后续登录时作为后台命令宿主启动，关闭只取消后续登录启动，不结束当前进程。系统状态为需要用户批准时，开关仍显示开启，并在开关左侧以灰字显示“未批准”；获得批准后不显示额外状态文字。
- 系统设置组提供“Finder 扩展”和“完全磁盘访问”两行。每行左侧只有图标和标题，右侧使用“设置...”按钮打开对应的系统设置位置。

“Finder 扩展”以绿色状态标识表示系统报告为已启用，以灰色状态标识表示未启用。“完全磁盘访问”使用固定的语义图标，不显示或推断当前授权状态。

页面不提供辅助功能权限选项。

### 右键菜单

右键菜单页按产品声明顺序列出全部固定功能。每行使用与 Finder 菜单一致的图标和标题，最右侧提供显示开关。

依赖外部应用的功能在开关左侧显示安装状态：应用可用时显示“已安装”；未安装时显示灰色“未安装”，整行和开关使用系统禁用的灰色外观且不可操作。安装状态变化不改写已保存的显示开关值。

外部应用缺失时，状态页使用统一的缺失应用占位图标。

总开关关闭时，功能列表仍然可见，但所有功能开关均处于系统禁用的灰色状态；重新开启后恢复原有配置和交互。

状态页不提供功能排序、菜单命名、质量参数或外部应用路径配置。
