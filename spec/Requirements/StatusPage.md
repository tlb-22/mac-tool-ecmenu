# 状态页

应用状态页显示当前版本，左侧导航提供 `General` / `通用`、`Context Menu` / `右键菜单` 与 `File Templates` / `文件模板` 三个页面。

首次打开默认进入 General / 通用，后续打开恢复用户上次选择的页面。当前不可操作的控件使用系统禁用状态。

## 通用

通用页提供 Enable ECMenu / 启用 ECMenu 和 Open at Login / 登录时打开两个开关。

- Enable ECMenu / 启用 ECMenu 默认开启。关闭后 Finder 不再显示任何本产品菜单，但保留每项命令原有的显示配置，已经开始的任务继续执行。Finder Extension 未启用时，仅此项禁用且保留用户保存的值；登录启动、系统设置入口和右键菜单配置不受影响。
- Open at Login / 登录时打开默认关闭，并按用户操作申请或取消系统登录项登记。需要用户批准时，开关仍显示开启并给出本地化的未批准状态；获得批准后不显示额外状态。具体运行效果见[应用生命周期](ApplicationLifecycle.md#登录启动与后台运行)。

通用页还提供 Finder Extension / Finder 扩展和 Full Disk Access / 完全磁盘访问两个本地化的设置入口，分别打开对应的系统设置位置。

“Finder 扩展”显示系统报告的启用状态，并向辅助功能提供本地化的状态值；两个系统设置按钮的辅助功能名称分别说明打开的设置位置。“完全磁盘访问”不显示或推断当前授权状态。页面不提供辅助功能权限选项。

## 右键菜单

右键菜单页按保存的顺序列出全部固定功能入口，并为每项提供显示开关和拖拽排序入口。初始顺序见[Finder 菜单](FinderMenu.md#结构与顺序)。“新建文件”的开关控制整个模板子菜单，排序时也作为完整入口移动。

依赖外部应用的命令显示本地化的已安装或未安装状态。应用不可用时该项显示开关禁用；安装状态变化不改写已保存的显示开关值或顺序。

总开关关闭时，命令列表仍然可见，但所有显示开关均禁用；重新开启后恢复原有配置和交互。隐藏的命令、依赖应用未安装的命令以及总开关关闭时的命令均可排序。

右键菜单页不提供固定功能的命名、质量参数或外部应用路径配置。排序交互遵循下方[列表排序](#列表排序)。

配置状态的跨进程同步见[菜单配置](../Technical/Runtime/CommandMenuSettings.md)。

## 文件模板

文件模板页提供普通文件模板的导入，并在每个模板行展示文件类型图标、菜单显示名、默认文件名以及打开、更换和删除操作。

文件类型图标依据已保存的默认文件名后缀由系统提供；默认文件名保存成功后更新，无后缀或系统无法识别时显示通用文档图标。图标随模板行一起移动。

模板列表支持拖拽排序，列表顺序对应 Finder“新建文件”子菜单顺序。开始拖拽时退出当前名称编辑并立即提交该名称，沿用名称校验和失败反馈；名称提交与最终顺序提交分别完成。名称保存失败时保留输入和编辑焦点，顺序不提交。取消拖拽不撤回已经保存的名称。

显示名和默认文件名支持原位编辑：单击名称区域或通过键盘导航聚焦时立即进入编辑，结束后恢复内容展示，名称位置和列表布局保持稳定。名称编辑也向辅助功能开放。

每个名称独立提交：按 Enter 或离开输入框时保存，点击页面空白区域也会保存并退出编辑，按 Esc 撤销本次编辑。输入无效或保存失败时保留当前输入和编辑焦点，每次提交失败仅播放一次系统默认错误提示音。

从一个名称点击另一个名称时，保存当前编辑后直接进入目标字段；保存期间接收的目标点击等待同一次提交，连续选择时以最后点击的字段为目标；失败时继续保留原字段的输入和编辑焦点。

打开操作使用系统默认应用打开当前保存的模板文件；更换操作在用户确认选择的普通文件后独立提交。读取失败时显示错误与重试入口；有效空清单仍可添加模板。导入、打开、更换或删除失败时提供明确反馈。

文件操作进行时保持列表和控件外观稳定，暂停接收新的文件操作与名称编辑请求。短操作直接呈现完成结果，耗时较长的文件读写显示进度反馈。

模板类型、内部副本、初始化和两种名称的生成与重复规则见[新建文件](Features/NewFile.md#模板管理)。

## 列表排序

右键菜单和文件模板的每一行左侧都有明确的拖拽提示。可从提示或行内非控件区域拖动整行；名称输入、开关与操作按钮各自响应原有操作。拖动时呈现正在移动的行，并清楚显示待插入位置。

完成一次实际改变位置的拖拽后自动保存顺序一次，不提供单独的保存步骤。取消拖拽或放回原位置不保存顺序。重启后恢复保存顺序；Finder 后续菜单在应用新配置后使用该顺序。

排序入口向辅助功能提供可理解的名称以及上移、下移操作；每次完成有效移动同样自动保存。无法继续向某方向移动时，不产生变更。
