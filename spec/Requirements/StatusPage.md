# 状态页

应用状态页显示当前版本，并提供 `General` / `通用` 与 `Context Menu` / `右键菜单` 两个页面。

首次打开默认进入 General / 通用，后续打开恢复用户上次选择的页面。当前不可操作的控件使用系统禁用状态。

## 通用

通用页提供 Enable ECMenu / 启用 ECMenu 和 Open at Login / 登录时打开两个开关。

- Enable ECMenu / 启用 ECMenu 默认开启。关闭后 Finder 不再显示任何本产品菜单，但保留每项命令原有的显示配置，已经开始的任务继续执行。Finder Extension 未启用时，仅此项禁用且保留用户保存的值；登录启动、系统设置入口和右键菜单配置不受影响。
- Open at Login / 登录时打开默认关闭，并按用户操作申请或取消系统登录项登记。需要用户批准时，开关仍显示开启并给出本地化的未批准状态；获得批准后不显示额外状态。具体运行效果见[应用生命周期](ApplicationLifecycle.md#登录启动与后台运行)。

通用页还提供 Finder Extension / Finder 扩展和 Full Disk Access / 完全磁盘访问两个本地化的设置入口，分别打开对应的系统设置位置。

“Finder 扩展”显示系统报告的启用状态，并向辅助功能提供本地化的状态值；两个系统设置按钮的辅助功能名称分别说明打开的设置位置。“完全磁盘访问”不显示或推断当前授权状态。页面不提供辅助功能权限选项。

## 右键菜单

右键菜单页按[产品声明顺序](FinderMenu.md#结构与顺序)列出全部固定命令，并为每项提供显示开关。

依赖外部应用的命令显示本地化的已安装或未安装状态。应用不可用时该项禁用；安装状态变化不改写已保存的显示开关值。

总开关关闭时，命令列表仍然可见，但所有显示开关均禁用；重新开启后恢复原有配置和交互。

状态页不提供功能排序、菜单命名、质量参数或外部应用路径配置。

配置状态的跨进程同步见[菜单配置](../Technical/Runtime/MenuConfiguration.md)。
