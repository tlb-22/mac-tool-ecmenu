# 压缩图片

## 正常行为

### 菜单与输入

菜单名称为 `压缩图片`。它只在 Finder 的项目上下文中显示，并同时满足以下条件：

- 至少选中一个对象。
- 所有选中对象都是普通文件。
- 每个文件的类型都属于当前系统 ImageIO 支持的图片输入类型。

选择集合中包含文件夹、PDF、类型无法识别的文件或 ImageIO 不支持的文件时，整条菜单隐藏。目录空白处和侧边栏上下文不显示该菜单。Finder Extension 只按文件类型判断菜单可见性，不在构建右键菜单时解码图片。

单选和多选使用相同行为。多图像容器只输出一张 JPG：使用容器的主图像；没有独立主图像语义时使用第一帧，GIF 因而使用第一帧。

### 设置窗口

点击菜单后由主应用显示一个设置窗口：

- 设置使用独立窗口，允许关闭和最小化，但不允许调整大小。
- 设置窗口是非模态的，不阻塞新建 TXT、拷贝路径、隐藏或显示项目、进入外部应用等其他右键命令；这些命令在窗口打开期间仍立即执行。
- 每次压缩请求独立冻结点击时的图片集合并显示自己的设置窗口。多个压缩窗口可以同时存在，确认或取消其中一个窗口只影响对应批次。
- 窗口提供`目标宽度`和`JPG 质量`两项设置。
- 目标宽度使用数字输入框，以像素为单位，默认值为 `1440`。
- 目标宽度只接受当前进程可表示的正整数。编辑时可以暂时清空字段；字母、空格、小数点、正负号、零以及溢出的整数在输入或粘贴时立即拒绝。
- JPG 质量使用滑动条和当前值，范围为 `0...10` 的整数，步长 `1`，默认 `8`。
- 输入不合法时显示错误信息；用户可以选择`压缩`或`取消`。

确认后持久化两个设置，下一次打开时恢复最后一次确认的值；点击`取消`或关闭窗口都不修改设置，也不执行转换。窗口最小化不改变当前输入。

质量线性映射到 ImageIO 的 `0.0...1.0`，即界面值除以 `10`。`0` 表示最大压缩，`10` 表示最高质量。

### 进度与取消

用户确认设置后，压缩批次开始报告以图片为单位的确定进度；设置窗口等待期间不产生进度任务。每张图片无论成功或失败，只要已经到达终态，已处理数量就增加一。

- 任务持续约一秒后才显示进度，快速完成的批次不闪现窗口。
- 进度由[主应用共享任务窗口](Main.md#长时间命令进度)承载，任务名称为“压缩图片”，进度文本表示“已处理图片数 / 图片总数”。
- 多个并发批次在共享窗口中各占一行并独立推进。
- 点击取消只登记取消意图。当前图片完整到达成功或失败终态后停止处理剩余图片，不中断单项编码或文件写入。
- 取消后保留并选择已经完整生成的图片；已经产生的错误继续遵守批量错误反馈规则。
- 用户手动关闭进度窗口只隐藏关闭瞬间已经显示的压缩任务，不取消它们；这些任务不会随窗口再次出现，之后开始并达到显示阈值的新任务仍可重新显示窗口。

### 缩放与编码

- 输出格式固定为 JPG，扩展名统一为 `.jpg`。
- 根据应用视觉方向后的宽度等比例缩放，高度由原始宽高比计算。
- 原始宽度大于最大宽度时缩小到指定宽度；原始宽度不超过最大宽度时不放大，但仍重新编码为 JPG。
- 缩放使用系统高质量插值。
- 透明区域合成到白色背景。
- 输出保持正确视觉方向，不保留 EXIF、GPS、XMP、相机信息或容器中的其他帧。
- 源文件始终保留，不移动、不修改、不删除。

### 输出名称、顺序与时间

输出写入每个源文件的同级目录，首选名称为源文件基础名加 `.jpg`。不覆盖任何已有文件；发生冲突时依次使用：

```text
photo.jpg
photo_copy.jpg
photo_copy2.jpg
photo_copy3.jpg
```

如果首选名称本身已经以 `_copy` 或 `_copy` 加数字结尾，后续候选延续该序号，不生成重复的 `_copy_copy`。如果数字已经无法继续递增，则保留完整首选基础名，并以它为新的基础依次追加 `_copy`、`_copy2`；任何外部文件名都不得使主应用崩溃。例如 `photo_copy9223372036854775807.jpg` 冲突后的候选为 `photo_copy9223372036854775807_copy.jpg`。

多选输入按 Finder 风格的本地化文件名顺序处理。确认执行时取得统一基准时间；排序后的第一个成功输出使用基准时间，后续项目按照输入序号每项递增一秒。输出文件的创建时间和修改时间设置为同一对应时间；某项转换失败不会改变其他项目预定的时间位置。

转换结束后，成功输出全部保留并由 Finder 自动选中。全部成功时不显示通知、声音或结果弹窗。

## 异常行为

- 批量转换允许部分成功，已成功结果不回滚并继续由 Finder 选中。
- 源文件或目标目录权限不足或只读时，整个批次结束后显示一次汇总弹窗，各类原因统一表述为“没有写入权限”。单个失败对象显示名称，多个失败对象显示数量；已经产生其他输出时在命令名称中加入“部分”。
- JPG 已生成但时间属性写入失败时，在同一弹窗中另起一行说明“图片已压缩但遇到问题：时间属性写入失败”。
- 文件在执行前失效、内容损坏、解码或编码失败及其他罕见错误，记录本地日志并播放一次系统默认错误提示音，不显示弹窗。
- 同一批次同时包含可弹窗错误和罕见错误时只显示一次汇总弹窗，不额外播放提示音。

对应技术设计见[压缩图片技术方案](../Technical/ImageCompression.md)。
