# 隐藏项目 / 显示项目

Finder 提供两个名称固定的独立一级菜单项：

```text
隐藏项目
显示项目
```

两个命令不合并为动态菜单项，分别拥有独立的显示开关，并按选中项状态独立决定是否出现。

## 操作对象

| Finder 上下文 | `隐藏项目` | `显示项目` | 操作对象 |
|---|---|---|---|
| 目录空白处 | 不显示 | 不显示 | 无 |
| 单个或多个选中项目 | 至少有一个普通可见对象时显示 | 至少有一个普通隐藏对象时显示 | 全部选中项目 |
| 侧边栏文件夹 | 不显示 | 不显示 | 无 |

- 目录空白处和侧边栏不提供可见性操作，即使 Finder 仍保留选择也不显示两个命令。
- 即使选择了当前目录中的全部项目，只要右键发生在选中项目上，仍属于选中项目上下文。
- 文件夹和 package 作为一个对象处理，不修改内部内容。
- 符号链接作为一个对象处理，不跟随到链接目标。
- 单选、多选以及文件与文件夹混选均可处理。

## 菜单状态

判断菜单项是否出现时，名称以 `.` 开头的对象完全排除在外，既不视为普通可见对象，也不视为普通隐藏对象。

| 排除点号名称后的已知状态 | `隐藏项目` | `显示项目` |
|---|---|---|
| 至少有一个可见对象，没有隐藏对象 | 显示 | 不显示 |
| 没有可见对象，至少有一个隐藏对象 | 不显示 | 显示 |
| 可见与隐藏对象都至少有一个 | 显示 | 显示 |
| 没有任何已知状态的普通对象 | 不显示 | 不显示 |

无法读取隐藏状态的普通对象不促成任何命令显示；其他已知对象仍按上表判断。

## 隐藏状态

- `隐藏项目` 把普通名称对象的 macOS 文件隐藏属性设为隐藏，已经隐藏的对象保持不变。
- `显示项目` 清除普通名称对象的 macOS 文件隐藏属性，已经可见的对象保持不变。
- 路径和文件名始终不变，不添加或删除 `.` 前缀。
- 名称以 `.` 开头的对象由文件名决定隐藏状态：执行 `隐藏项目` 时视为已经满足，执行 `显示项目` 时静默跳过。
- 每个显示的命令都作用于完整选择集合，其中已经处于目标状态的对象保持不变。

## 失败行为

权限不足或只读文件系统导致一个或多个对象失败时，在操作结束后显示一次汇总弹窗，两类原因统一表述为“没有写入权限”。单个失败对象显示名称，多个失败对象显示数量；存在成功对象时使用“无法隐藏部分项目”或“无法显示部分项目”。

项目在执行前失效或发生其他罕见文件系统错误时，使用[通用非弹窗反馈](../CommandBehavior.md#错误反馈)；与可弹窗错误同时发生时也遵循该页的统一汇总规则。

对应技术设计见[隐藏项目 / 显示项目](../../Technical/Features/Visibility.md)。
