# 进入外部应用

产品固定提供 `Open in Visual Studio Code` / `进入 Visual Studio Code` 和 `Open in iTerm2` / `进入 iTerm2` 两个独立命令。

## 菜单与目标

| Finder 上下文 | Visual Studio Code 命令 | iTerm2 命令 |
|---|---|---|
| 目录空白处 | 将当前目录作为项目打开 | 以当前目录作为工作目录打开窗口 |
| 侧边栏中的文件夹 | 将该文件夹作为项目打开 | 以该文件夹作为工作目录打开窗口 |
| 单个文件夹 | 将该文件夹作为项目打开 | 以该文件夹作为工作目录打开窗口 |
| 单个文件 | 直接打开该文件，不替换为父目录项目 | 不显示 |
| 多选 | 不显示 | 不显示 |

目录空白处按当前目录语义处理，即使 Finder 仍保留选择，也不把选择视为本次目标。

package 作为目录处理。符号链接跟随最终目标判断是否满足对应命令的文件或目录约束，但交给外部应用的仍是用户选中的原始路径；断开的符号链接不显示命令。

Visual Studio Code 是否新建或复用窗口由其自身设置决定。iTerm2 固定以目标文件夹作为工作目录打开窗口。

## 应用依赖

两个命令分别固定依赖 Visual Studio Code 和 iTerm2，不回退到其他编辑器或终端。对应应用不可用时，Finder 不显示该命令；状态页的安装状态和显示开关遵循[右键菜单设置](../StatusPage.md#右键菜单)的统一行为。

## 失败行为

菜单显示后应用被移除、目标失效、应用无法启动或目标无法打开时显示本地化错误弹窗，正文说明对应应用无法打开目标。

应用定位和启动方式见[进入外部应用](../../Technical/Features/OpenInApplications.md)。
