# 功能

当前产品提供以下固定命令：

| 业务能力 | Finder 命令 | 需求 |
|---|---|---|
| 创建文本文件 | `新建 TXT` | [新建 TXT](NewTextFile.md) |
| 复制路径 | `拷贝路径` | [拷贝路径](CopyPath.md) |
| 修改可见性 | `隐藏项目`、`显示项目` | [隐藏项目 / 显示项目](Visibility.md) |
| 处理图片 | `压缩图片` | [压缩图片](ImageCompression.md) |
| 打开外部应用 | `进入 Visual Studio Code`、`进入 iTerm2` | [进入外部应用](OpenInApplications.md) |

七个 Finder 命令分别拥有独立的显示开关。功能集合、命令名称和行为固定：新建文件的类型固定为 TXT，编辑器固定为 Visual Studio Code，终端固定为 iTerm2。

命令的菜单顺序和通用显示规则见[Finder 菜单](../FinderMenu.md)，开关的界面行为见[状态页](../StatusPage.md#右键菜单)。
