# 功能

产品提供以下功能：

| 业务能力 | 需求 |
|---|---|
| 按模板创建文件 | [新建文件](NewFile.md) |
| 复制路径 | [拷贝路径](CopyPath.md) |
| 修改可见性 | [隐藏项目 / 显示项目](Visibility.md) |
| 处理图片 | [压缩图片](ImageCompression.md) |
| 打开外部应用 | [进入外部应用](OpenInApplications.md) |

七个 Finder 一级入口分别拥有独立的显示开关。“新建文件”的开关控制其完整模板子菜单，模板由用户管理；编辑器固定为 Visual Studio Code，终端固定为 iTerm2。

命令名称、菜单顺序和通用显示规则见[Finder 菜单](../FinderMenu.md)，开关的界面行为见[状态页](../StatusPage.md#右键菜单)。
