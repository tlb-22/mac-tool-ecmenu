# 拷贝路径

## 菜单与操作对象

菜单名称为 `Copy Path` / `拷贝路径`，在以下上下文可用：

| Finder 上下文 | 拷贝对象 |
|---|---|
| 目录空白处 | 当前可见目录本身；忽略窗口中残留的选中项 |
| 单个或多个选中项目 | 全部选中项目 |
| 侧边栏项目 | 该项目 |

## 剪贴板内容

剪贴板内容使用绝对 POSIX 路径：

```text
/Users/me/Projects/demo/index.ts
```

- 不包含 `file://`。
- 不执行 shell escaping，路径中的空格保持原样。
- 文件夹路径不添加尾随 `/`。
- 多选时按 Finder 提供的选择顺序每个项目写一行，不自行排序。
- 最后一行末尾不额外添加换行符。
- 符号链接拷贝链接目录项自身的路径，不解析链接目标；断开的符号链接仍可拷贝其路径。

## 失败行为

执行时任一目标已经不存在，则不写入不完整的路径集合。目标失效或剪贴板写入失败使用[通用非弹窗反馈](../CommandBehavior.md#错误反馈)。

剪贴板已经清空但字符串写入失败时，不恢复先前的剪贴板内容。

对应技术设计见[拷贝路径](../../Technical/Features/CopyPath.md)。
